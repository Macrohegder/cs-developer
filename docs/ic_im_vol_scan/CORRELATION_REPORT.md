# 三品种日历价差策略相关性分析报告

> 生成时间：2026-07-15  
> 分析区间：2022-07-22 ~ 2026-07-14（共同交易日 560 天）  
> 策略参数：IF@25% / IC@15% / IM@15%，其余参数一致

---

## 1. 分析目的

回答用户问题：IF、IC、IM 三个股指期货的日历价差套利策略，彼此之间的相关性高吗？组合配置是否真的能起到分散效果？

---

## 2. 日盈亏相关性

| 品种对 | 日盈亏相关系数 |
|:---|---:|
| IF - IC | **-0.28** |
| IF - IM | **-0.02** |
| IC - IM | **+0.20** |

**结论**：整体相关性很低，IF 与 IC 甚至呈轻微负相关。这是组合能够显著降低回撤的核心原因。

---

## 3. 月度盈亏相关性

| 品种对 | 月度盈亏相关系数 |
|:---|---:|
| IF - IC | **-0.41** |
| IF - IM | **+0.50** |
| IC - IM | **-0.11** |

**观察**：
- IF 与 IC 在月度维度上呈**中等负相关**（-0.41），分散效果最好。
- IF 与 IM 在月度维度上呈**中等正相关**（+0.50），但日度相关性几乎为零，说明短期波动不同步。
- IC 与 IM 月度相关性接近零（-0.11），分散效果较好。

---

## 4. 同涨同跌统计

| 品种对 | 同时持仓天数 | 同向天数 | 同向比例 |
|:---|---:|---:|---:|
| IF - IC | 32 | 15 | 46.88% |
| IF - IM | 32 | 16 | 50.00% |
| IC - IM | 163 | 103 | 63.19% |

**说明**：
- IF 因 25% 高阈值导致持仓天数极少，与 IC/IM 同时持仓仅 32 天，样本量较小。
- IC 与 IM 同时持仓 163 天，同涨同跌比例 63%，略高于 50%，但仍属中低相关。

---

## 5. 回撤重叠分析

| 品种对 | 共同回撤天数 | 任一回撤天数 | 重叠比例 |
|:---|---:|---:|---:|
| IF - IC | 27 | 525 | 5.14% |
| IF - IM | 2 | 174 | 1.15% |
| IC - IM | 146 | 528 | 27.65% |

**结论**：
- IF 与 IC、IF 与 IM 的回撤重叠比例极低（< 6%），说明三者很少同时亏损。
- IC 与 IM 的回撤重叠约 28%，相对较高，但仍能部分错峰。

---

## 6. 滚动相关性时变特征

从 `strategy_rolling_correlation.png` 可见：

- **IC-IM 相关性波动最大**：从 2023 年中的 -0.8 左右升至 2025 年的 +0.7 左右，呈现明显的时变性。
- **IF-IC 长期为负**：多数时间维持在 -0.2 ~ -0.5 之间，分散效果稳定。
- **IF-IM 相关性较低**：围绕 0 轴波动，偶发极端值。

**启示**：相关性不是静态的，在市场剧烈波动或极端行情下，原本低相关的策略可能短期趋同。但这 4 年回测显示，整体仍保持较好的分散效果。

---

## 7. 为什么组合回撤能做到 -0.27%？

组合绩效优异的关键在于：

1. **低相关性**：三个品种日历价差的收益驱动因素不同（IF 大盘蓝筹、IC 中盘、IM 小盘），贴水结构和波动特征存在差异。
2. **错峰交易**：IF 因高阈值很少交易，天然起到"空仓避险"的作用；IC 和 IM 虽然同时持仓较多，但盈亏节奏并不同步。
3. **IM 高收益低回撤**：IM 单策略夏普 2.74、回撤 -0.53%，为组合提供了稳定的安全垫。

---

## 8. 结论

- **三品种日历价差策略相关性整体不高**，IF 与 IC 甚至是负相关。
- 这种低相关性解释了为什么组合后夏普能到 2.12、回撤仅 -0.27%。
- 需要注意：**IC-IM 相关性存在明显时变性**，在极端市场环境下可能短期上升，组合并非完全没有尾部风险。
- 当前参数下，组合具备良好的分散化效果，适合作为低风险套利策略配置。
