## 1. 工作摘要

本次优化在原有日历价差套利策略基础上，新增以下增强模块：

- **可配置波动窗口**：支持 10/20 日年化波动率计算
- **止盈 / 止损**：按 pair 名义市值比例触发
- **季月过滤**：只交易 3/6/9/12 月合约
- **提前移仓**：近月到期前 N 天平仓，避免交割月流动性风险
- **多品种支持**：IC / IM / IF 可独立配置

通过 324 组参数扫描，筛选出 **IC 盈利且 IM 夏普 >= 1.8** 的共同参数组合，并单独跑一次完整版回测进行确认。

## 2. 推荐最优参数

**核心发现**：`only_quarterly=True` 是本次优化最关键的提升点。季月合约流动性更好、价差结构更稳定，能显著降低交易成本和噪声交易。

## 5. 核心逻辑解释

### 5.1 为什么"只做季月"有效？

1. **流动性集中**：季月合约（3/6/9/12）是股指期货的主力合约，买卖价差更窄，冲击成本更低。
2. **价差结构稳定**：非季月合约（如 1/2/4/5 月）流动性差，远近月价差容易受个别合约供需扰动，产生噪声信号。
3. **降低换月次数**：每季度交易一次，减少佣金和滑点累积。

### 5.2 为什么远月贴水时做多近月做空远月能赚钱？

- 当市场恐慌时，远月贴水扩大（远月比近月便宜）。
- 做多近月、做空远月，赚取的是 **远近价差的收敛**（即贴水修复），而非单边看涨指数。
- 近月临近到期时向现货收敛，远月受情绪影响更大，价差回归带来套利空间。

### 5.3 波动率过滤的作用

- 只在指数 20 日年化波动 >= 15% 时开仓。
- 高波动往往伴随流动性折价和错误定价，此时套利收益更稳定。
- 低波动期间价差波动小，扣除成本后收益微薄，过滤掉可减少磨损。
